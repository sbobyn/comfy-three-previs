# Gamepad

Fly the shot camera with a standard browser gamepad (an Xbox controller or similar) in **Shoot → Fly camera**. Connect it, press any button so the browser sees it, then center the sticks and release the triggers to arm.

| Control | Game layout (default) | RC Mode 2 |
|---|---|---|
| Left stick | Move forward, back, left, right | Turn (left, right) and up, down |
| Right stick | Aim (turn and tilt) | Move forward, back, left, right |
| RT / LT | Up / down | – |
| LB (hold) | Slow: 0.3× move and aim | Slow |
| RB (hold) | Fast: 2.5× move | Fast |
| A | Take control → start recording → stop | Same |

The gamepad must report the browser's standard mapping. Keep the take to use it as the shot's camera keys. Phone control is in [director-phone.md](director-phone.md).
