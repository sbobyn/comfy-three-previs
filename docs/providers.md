# Providers, settings and costs

Start with paid execution disabled and no credentials. For later Cloud use, copy
`.env.example` to `.env` **only if `.env` does not already exist**, then edit it locally.
Set `COMFY_CLOUD_API_KEY` to your own Comfy Cloud key. Never put secrets in a scene,
`VITE_*` setting, bug report or Git. `pnpm start` loads `.env`; direct `node` without
`--env-file-if-exists=.env` does not. Shell exports override `.env`: the review shell's
`PREVIS_ALLOW_PAID=0` remains authoritative until you deliberately change it.
Restart your own server after configuration changes.

Use **Setup → Check Cloud access** for a schema/access check. Generation sends the
selected prompts and media to the provider. Only after approving a particular paid
experiment should you enable `PREVIS_ALLOW_PAID=1`, configure account/project caps,
review the quote and approve the request. Reference images, graders and retries
can add cost. Estimates/reservations are not a provider bill cap. MCP tools can
execute with a supplied budget without another UI confirmation; keep paid off
while exploring agent control. No paid generation was run for this package.

For local ComfyUI, set `PREVIS_COMFY_URL` (default `http://127.0.0.1:8000`) and install
the selected workflow's compatible models/nodes separately. Video Lab does not
install ComfyUI or models. Local computation uses your hardware; partner nodes
may still require `COMFY_API_KEY` and incur provider charges. Local generation,
Cloud generation and provider prices remain untested for this review version.
See the spending controls below and the [workflow guide](first-use.md).

## Spending controls

Every paid run reserves its estimate before dispatch. Work that would exceed an account or project cap is refused before it is sent. Estimates include reference images and any paid grader; reservations add a safety margin (10% by default). The Jobs panel shows settled spend and outstanding reservations. Estimates are not a provider-enforced billing limit.

| `.env` setting | Purpose |
|---|---|
| `COMFY_CLOUD_API_KEY` | Your Comfy Cloud key; never commit it. |
| `PREVIS_ALLOW_PAID` | `1` enables paid work; off by default. |
| `PREVIS_BUDGET_CAP_USD` | Account cap in USD, per month by default. Unset means no cap. |
| `PREVIS_BUDGET_PROJECT_CAP_USD` | Cap in USD per project. Unset means no cap. |
| `PREVIS_BUDGET_MARGIN` | Reservation safety margin, default 10%. |
| `PREVIS_COMFY_URL` | Local ComfyUI URL. |
| `PREVIS_DATA_DIR` | Project storage, default `.previs/`. |
| `PREVIS_LIBRARY_DIR` | Shared asset library, default under the data directory. |
| `PORT` | App port, default `5190`. |
| `PREVIS_FFMPEG`, `PREVIS_FFPROBE` | Executable paths when FFmpeg tools are not on `PATH`. |

A batch dry run needs no key and sends no generation requests. With the app running, replace the project ID below with the one from your project URL:

```sh
curl -s -X POST http://127.0.0.1:5211/api/director/batch \
  -H 'content-type: application/json' \
  -d '{"projectId":"<id from the project URL>","steps":["stills","videos"],"tier":"draft","maxCostUsd":0,"dryRun":true}'
```

Agents can use `previs_director_batch_generate` with `dryRun: true`. `pnpm usage:report` reads provider billing; `pnpm usage:settle` compares billed model/time buckets with the ledger. Both need your Cloud key and only read data. The ledger lives in `PREVIS_DATA_DIR/budget/`; uncertain jobs retain reservations because a charge may still arrive.
