Blender & its actual MCP server

Use a running GUI Blender (verified with 4.5.4), not background mode. Install and enable the matching official addon, then start its socket server in Blender.

Selected upstream: mcp-for-blender 2.2.2 · pinned source · MIT. Python 3.10+ and an MCP command such as uv are required.

export PREVIS_BLENDER_MCP_COMMAND=uv
export PREVIS_BLENDER_MCP_ARGS='["tool","run","--from","git+https://github.com/ahujasid/mcp-for-blender@5a3618fccb2d982d0dd61e7a1879912c3100073b","mcp-for-blender"]'
export BLENDER_HOST=127.0.0.1
export BLENDER_PORT=9876
pnpm start

The first uv invocation may fetch Python dependencies. No package installation or global agent setup happens automatically in this page. Previs disables upstream MCP telemetry; the addon update check can be disabled with BLENDERMCP_NO_UPDATE_CHECK=1 when launching Blender.

Video encoding

Install FFmpeg and FFprobe on PATH. PREVIS_FFMPEG and PREVIS_FFPROBE may select existing executables. No installation runs automatically.

Comfy Cloud

Set COMFY_CLOUD_API_KEY in the server environment using an existing credential. Never paste it into a graph or project. The current adapter uses deprecated Cloud v1; live validation is required for every backend. Paid execution remains disabled unless PREVIS_ALLOW_PAID=1 is deliberately configured after review; every request still requires a matching approval.

Local Comfy

Start your existing local Comfy instance. Default: http://127.0.0.1:8000. Set PREVIS_COMFY_URL to another loopback HTTP origin if needed. No account, auth setup or model download is required for native passthrough.

Checks do not submit jobs. Coordinate shared backend use; the queue must be empty before a passthrough submission. The app never interrupts or clears another task's queue.
